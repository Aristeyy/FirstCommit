# Первый коммит

Чат-бот и мини-приложение в MAX, которые помогают студентам IT-направлений найти первую стажировку
под свой профиль и не пропустить дедлайн набора.

> README будет дополнен по чек-листу кейса: сценарий, архитектура, запуск одной командой,
> переменные окружения, порты, данные, проверка, ограничения. План — в [docs/PLAN.md](docs/PLAN.md).

## Быстрый старт (черновик)
```bash
cp .env.example .env   # заполнить MAX_BOT_TOKEN и остальное
docker compose up -d --build
```
